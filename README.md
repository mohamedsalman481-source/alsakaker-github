# السكاكر — ليلى وليالي

لعبة منصات عائلية تعمل مباشرة داخل المتصفح، وتضم 15 مرحلة متدرجة الصعوبة، ووحشًا مختلفًا في نهاية كل مرحلة، وقرارات تؤثر في المخزون والنقاط وطريق اللعب.

## رابط اللعبة بعد النشر

بعد تفعيل GitHub Pages سيصبح الرابط بالشكل التالي:

`https://USERNAME.github.io/REPOSITORY-NAME/`

استبدل `USERNAME` باسم حساب GitHub و`REPOSITORY-NAME` باسم المستودع.

## أسرع طريقة للنشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub باسم مثل `alsakaker-game` واجعله Public.
2. فك ضغط الحزمة وارفع **محتويات هذا المجلد نفسها** إلى المستودع، بحيث يظهر `index.html` في المستوى الرئيسي.
3. افتح المستودع ثم: `Settings` ← `Pages`.
4. في `Build and deployment` اختر `Deploy from a branch`.
5. اختر فرع `main` والمجلد `/(root)` ثم اضغط `Save`.
6. انتظر دقيقة أو دقيقتين، ثم افتح الرابط الذي سيظهر داخل صفحة Pages.

## ملفات المشروع

- `index.html`: اللعبة كاملة.
- `manifest.webmanifest`: بيانات تثبيت اللعبة على الهاتف.
- `service-worker.js`: تشغيل اللعبة بعد أول زيارة حتى مع انقطاع الإنترنت.
- `icons/icon.svg`: أيقونة اللعبة.
- `.nojekyll`: يمنع GitHub Pages من إجراء تحويلات غير مطلوبة.

## التحكم

| الوظيفة | لوحة المفاتيح |
|---|---|
| الحركة | الأسهم أو `A` و`D` |
| القفز | `Space` أو السهم لأعلى أو `W` |
| الهجوم | `J` |
| تبديل البطلة | `Q` |
| قلب الحلوى | `1` |
| فقاعة السكر | `2` |
| حذاء النعناع | `3` |
| مساعدة ماما أثناء الوحش | `G` |
| مساعدة بابا أثناء الوحش | `H` |
| الإيقاف المؤقت | `Esc` |

تظهر أزرار لمس تلقائيًا داخل اللعبة، لذلك تعمل على الهاتف والتابلت أيضًا.

## ملاحظات مهمة

- لا تحتاج اللعبة إلى قاعدة بيانات أو خادم خلفي.
- تقدم كل لاعب يُحفظ محليًا على جهازه ومتصفحه.
- فتح اللعبة من جهاز آخر يبدأ ملف تقدم مستقلًا.
- كل الملفات محلية ولا تستخدم مكتبات أو خدمات خارجية.

## تحديث اللعبة لاحقًا

استبدل الملفات المعدلة داخل المستودع ثم نفّذ Commit. سيحدّث GitHub Pages الرابط نفسه تلقائيًا. قد يحتاج المتصفح إلى تحديث قوي مرة واحدة بسبب التخزين المؤقت.
